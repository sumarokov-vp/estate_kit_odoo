# Замечания по тестированию CRM

**Дата:** 27.04.2026  
**Область:** CRM — система заявок от покупателей, регистрация

---

## Замечания

### 1. Данные из мини-карточки не переносятся в полную карточку заявки

При создании заявки открывается мини-карточка, в которой заполняются:
- Тип сделки (например, "продажа")
- Тип недвижимости (например, "коммерция")
- Имя и телефон контакта

После нажатия "Создать" открывается полная карточка заявки, однако в ней не заполнено ничего из введённых данных:
- Тип сделки — пусто
- Тип объекта — пусто
- Имя контакта — пусто
- Телефон контакта — пусто

### 2. Набор полей потребности должен зависеть от типа объекта

В полной карточке заявки поля раздела "Потребности" должны отображаться в зависимости от выбранного типа объекта. Например, для коммерческой недвижимости поле "Количество комнат" не актуально и должно быть скрыто.

### 3. Площадь участка обязательна для земли, коммерции и домов

Для следующих типов объектов вместе с площадью объекта должно присутствовать поле "Площадь участка":
- Земля
- Коммерция
- Дом

### 5. Автоматическое название лида

Сейчас название лида формируется по умолчанию как "possibility + имя клиента". Нужно изменить: вместо имени клиента использовать тип объекта. Например: "Иванов Иван — Дом" или "Коммерция".

Итоговый формат: **Тип объекта + Имя клиента** (например: "Дом · Иван Иванов", "Коммерция · Иван Иванов").

### 6. Переключатель валюты для диапазона цены

В полях "Цена от" и "Цена до" добавить переключатель валюты: **доллар / тенге**.

---

### 4. Идентификация контакта по телефону при создании заявки

В шапке карточки заявки отображаются поля "Контакт" и "Телефон". Логика заполнения при создании через мини-карточку:

1. Пользователь вводит имя и телефон в мини-карточке
2. После нажатия "Создать" система ищет контакт по введённому номеру телефона
3. Если контакт найден — подставляется в поле "Контакт"
4. Если контакт не найден — автоматически создаётся новый контакт на основе введённых имени и телефона
